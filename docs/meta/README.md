# Meta Deck Audits

Generated meta-deck support notes live here. Run:

```powershell
npm.cmd run audit:meta-decks
```

The script extracts Riftbound.gg guide deck slugs, fetches the corresponding
DotGG deck API payloads, resolves card names against the local RiftForge card
cache, and records conservative support blockers.

Uploaded exact export audits are generated by:

```powershell
npm.cmd run import:uploaded-meta-decks
```

Those raw files live in `decks/meta/raw/`, normalized JSON lives in
`decks/meta/normalized/`, and the generated summary is
`docs/meta/UPLOADED_META_DECKS.md`.

Do not hand-edit generated archetype audit files unless the source extraction
cannot be rerun. Add interpretation and priority decisions to
`docs/META_DECK_SUPPORT.md`.
